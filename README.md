# Android Assistant

Personal lightweight Android voice assistant.

## Goals

- Minimal battery and RAM usage
- Voice activation
- Android system integration
- Local commands without AI
- Optional local AI
- Optional cloud AI
- Music control
- Calls and contacts
- Application launching
- System controls
- Messaging integrations
- Extensible tool architecture

## Architecture

Voice
→ Speech-to-Text
→ Command Router
→ Android Tools / AI
→ Action
→ Text-to-Speech
