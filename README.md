# Android Assistant (Оріон)

Особистий легкий голосовий асистент для Android. Розуміє українські команди і працює **без інтернету**:
інтернет потрібен лише один раз, щоб завантажити модель розпізнавання.

## Як це працює

```
«Оріон» → запис з VAD → нормалізація гучності → модель розпізнавання (офлайн)
        → CommandParser (правила) → Tool (дія) → TextToSpeech (відповідь)
```

| Пакет | Що всередині |
|---|---|
| `voice/` | Запис з мікрофона, VAD, слово активації «Оріон», озвучення |
| `asr/` | Каталог моделей, завантаження, рушії Moonshine / Parakeet (sherpa-onnx) і Vosk |
| `nlu/` | Розбір команд, числа словами, нечіткий пошук застосунків |
| `tools/` | Дії: ліхтарик, гучність, музика, таймер, будильник, застосунки, панелі, довідка |

## Моделі розпізнавання

Обираються на екрані **«МОДЕЛІ»**: завантажити, видалити, зробити активною.

| Модель | Завантаження | Результат на реальному записі «відкрий налаштування» |
|---|---|---|
| Moonshine uk (рекомендовано) | ~111 МБ | «відкриє налаштування» |
| Parakeet v3, 25 мов | ~487 МБ | «відкрить на влаштування» |
| Vosk uk | ~133 МБ | ще не тестувалась |

Жодна модель не ідеальна, тому парсер терпимий до типових помилок: «відкриє», «відкрить»,
«від країн налаштування» — усе це розуміється як «відкрий налаштування».

## Команди

| Скажи | Що станеться |
|---|---|
| «Увімкни / вимкни ліхтарик» | ліхтарик |
| «Голосніше», «тихіше», «гучність п'ятдесят відсотків», «вимкни звук» | гучність |
| «Пауза», «наступний трек», «увімкни музику» | плеєр |
| «Таймер на п'ять хвилин», «таймер на півгодини» | таймер |
| «Будильник на сьому тридцять», «розбуди о дев'ятій вечора», «пів на восьму» | будильник |
| «Відкрий телеграм», «запусти ютуб», «відкрий камеру» | будь-який застосунок за назвою |
| «Відкрий вайфай / блютуз», «режим польоту» | системна панель |
| «Котра година», «яке сьогодні число», «який заряд батареї» | відповідь голосом |

## Як додати команду

1. Клас, що реалізує `Tool` (приклад — `tools/FlashlightTool.kt`).
2. Рядок у `tools/ToolRegistry.kt`.
3. Правило в `nlu/CommandParser.kt` і тест у `app/src/test/.../CommandParserTest.kt`.

## Збірка

GitHub Actions на кожен push запускає тести і збирає debug-APK (артефакт `android-assistant-debug`).

## Плани

- Слово «Оріон» без Google: keyword spotter sherpa-onnx (зараз працює через системний SpeechRecognizer).
- Foreground-сервіс, щоб асистент слухав при згорнутому застосунку.
- Локальна LLM для фраз, які не впізнали правила.
